## Project Description

This is a **pixel-perfect, fully responsive, no-framework landing page** for **Headphonex**, a premium wireless headphone brand.

Built **from scratch using only HTML5 and CSS3** — no Bootstrap, no Tailwind, no JavaScript.

The design was created by **Nicolas Philippot**, UI/UX Designer.

**Live Figma File:** [Headphonex Homepage](https://www.figma.com/file/5ZkA14tAOMzQIIHLxalU3s/Homepage--Copy-?node-id=0-1&t=AtnVg4RyXzNVTzWJ-0)

## Features Implemented

- **100% Pixel-Perfect** match with the Figma design
- **Fully Responsive** (mobile ≤480px, tablet, desktop)
- Max content width: **1000px**, perfectly centered
- Hover effects:
  - Links → color `#FF6565`
  - Buttons → `opacity: 0.9`
- Smooth transitions and modern layout using Flexbox & Grid
- Semantic HTML5 structure
- Accessible contrast, alt texts, and focus states
- Optimized images and clean code
- Zero JavaScript — pure HTML/CSS

## Tech Stack

- HTML5 (semantic tags)
- CSS3 (Flexbox, Grid, Custom Properties, Responsive Design)
- Google Fonts: **Source Sans Pro**
- Custom font: **Spin Cycle OT** (used for logo)

## Responsive Breakpoints

| Screen Size | Behavior
|---------------|---------
| > 1000px      | Full desktop layout
| 768px – 1000px| Tablet adjustments
| ≤ 480px       | Mobile-first layout (stacked)
